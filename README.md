## Proyectos destacados

### [SKIPPY](https://github.com/reptilAndaluz/SKIPPY) · Sistema RAG local
Ingesta documentos PDF, los vectoriza en local y permite consultarlos desde terminal con un LLM ligero. Está optimizado para equipos con gráficos integrados.
**Python · LangChain · Ollama · ChromaDB**
Incluye tests con `pytest`, configuración centralizada, variables de entorno (`.env.example`) y hoja de ruta por fases.

**Python · JavaScript · HTML**

## Forma de trabajar

- **Documentación primero:** cada proyecto lleva README con instalación, uso y estructura.
- **Reproducibilidad:** dependencias con versiones fijadas y entornos virtuales.
- **Seguridad básica:** secretos fuera del repositorio (`.env` ignorado, `.env.example` versionado).
- **Calidad:** pruebas automatizadas y tipado estático donde es posible.
- **Control de versiones:** commits pequeños y descriptivos.
